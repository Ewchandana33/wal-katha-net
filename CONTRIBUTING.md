# Contributing

## Changes to `main`

- Submit changes through a pull request; direct pushes, force-pushes, and branch deletion are blocked.
- Required checks are `Type-check and production build` and `Cloudflare Pages`; the branch must be up to date with `main`.
- Non-draft PRs into `main` opened by `Ewchandana33` from this repository are queued for squash auto-merge; GitHub merges only after required checks pass.
- PRs from forks or other accounts are not auto-merged.
